# Experiment No. 02

## Experiment Name
**Study of Different Git Commands**

## Objectives

1. To understand the basic concepts and uses of Git.
2. To learn and execute different Git commands.
3. To manage and track changes in a project using Git.

## Theory

Git is a distributed version control system used to track changes in source code and manage project versions. It allows developers to create repositories, save changes, create branches, and collaborate with others.

### Some Common Git Commands

- `git init` – Creates a new Git repository.
- `git add` – Adds files to the staging area.
- `git commit` – Saves changes to the repository.
- `git status` – Shows the current repository status.
- `git log` – Displays commit history.
- `git branch` – Manages branches.
- `git merge` – Combines branches.
- `git clone` – Copies a remote repository.

## Result

Different Git commands were successfully studied and executed. The commands helped to initialize a repository, track files, commit changes, and manage project versions.

## Discussion

Git provides an efficient way to manage project files and maintain different versions of a project. By using commands such as `git add`, `git commit`, `git status`, and `git log`, changes can be tracked easily. Branching and merging also make collaborative software development easier.

## Conclusion

The experiment successfully introduced the basic Git commands and their practical uses. Git is an important tool for version control, project management, and collaborative software development.
